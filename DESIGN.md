# Calendar Bar design

Preserve the macOS menu interaction shown in the incumbent screenshot.
Use AppKit status items and native menus, system typography, system selection and focus states, and automatic light and dark appearances.
Keep ended events enabled and gray so their links remain accessible.
Keep the menu-bar title compact and show the full event name in the menu.
Use a small native preferences window for account connection and login-at-startup.
Do not add authored motion to the frequently opened menu or keyboard actions.
Use native button feedback and native progress indication for network requests.
Do not show event details, dashboards, notifications or decorative transitions beyond the requested menu behavior.
